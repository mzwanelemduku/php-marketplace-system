# php-marketplace-system
A PHP and MySQL marketplace system for managing products, users, sellers, and online purchases.

A web-based marketplace system built using PHP and MySQL.

## Features

- User registration
- User login
- Password hashing
- Product listing
- Product management
- Shopping cart
- Orders
- User accounts
- Admin dashboard

## Technologies

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap
- WAMP

## Installation

1. Clone the repository
2. Copy the project into the WAMP www directory
3. Create the MySQL database
4. Configure database connection
5. Open the project through localhost
